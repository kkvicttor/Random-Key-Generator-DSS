## 📌 Sobre o projeto

O Gerador de Senhas é uma aplicação desenvolvida em linguagem C
com o objetivo de permitir a criação de senhas aleatórias a partir
de critérios definidos pelo usuário.


## ⚙️ Funcionalidades

- Definição do tamanho da senha
- Utilização de letras maiúsculas
- Utilização de letras minúsculas
- Utilização de números
- Utilização de caracteres especiais
- Geração aleatória de senhas
